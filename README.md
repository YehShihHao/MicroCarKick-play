# 飆速足球 Micro Car Kick — 試玩版

**▶ 開始玩：https://yehshihhao.github.io/MicroCarKick-play/**

開一台廢土改裝的遙控小車，把足球撞進對方球門！這是開發中的 **M1 單機試玩版**：可以對 AI（三種難度）或兩人用同一台電腦對戰。

- **作者**：YehShihHao
- **版本**：見主選單底部（例如「M1 測試版 v0.1.2」）；各版下載見 [Releases](https://github.com/YehShihHao/MicroCarKick-play/releases)
- 建議用電腦的 Chrome / Edge 鍵盤操作；手機請**橫拿**遊玩（左半邊蘑菇頭開車、右下 Boost / 武器）
- 不用註冊、不用安裝、不蒐集資料；車庫配裝只存在你自己的瀏覽器裡

## 怎麼玩

先進 5 球獲勝；5 分鐘到了分數多的贏，平手打「黃金進球」。被進球而落後或平手時，可以選一張改裝零件卡翻盤，強化保留整場。每場隨機一種地形（柏油 / 冰原 / 沙地），開賽前 15 秒可以換輪胎。

| 動作 | 玩家 1 | 玩家 2 | 手機（橫拿） |
|---|---|---|---|
| 油門 / 倒車 | W / S | ↑ / ↓ | 左半邊蘑菇頭：往哪推就往哪開 |
| 轉向 | A / D | ← / → | （同上） |
| Boost | 左 Shift | 右 Shift 或 / | 右下 BOOST |
| 武器 | Space | Enter 或 . | 右下 武器 |
| 選改裝卡 | A / D + Space | ← / → + Enter | 點選卡片 |
| 暫停 | Esc | Esc | 右上 Ⅱ |

小提醒：鍵盤是「坦克式」操控，左右鍵讓車頭轉向；車頭前方的燈光就是前進方向，按倒車時車尾亮紅燈。
